# bazis-mcp 2.4.0

The first release. Requires Bazis 2.4 and the MCP Python SDK 2.

The MCP server of a Bazis project, run as `bazis-mcp` in the project directory:

- tools `list_packages`, `package_guide`, `project_info` and `run_doctor`, all read-only;
- the resource `bazis://packages/{name}/agents.md`;
- the prompts `add_package` and `audit_project`.

The catalog describes the Bazis packages 2.4.0.

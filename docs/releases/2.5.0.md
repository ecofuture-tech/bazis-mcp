# bazis-mcp 2.5.0

## Features

- The skeleton of a new project, the rules of Bazis for an agent and its tasks are moved
  here from bazis-cli, which builds its commands on them: `bazis.contrib.mcp.scaffold`
  (the files of a project, `.venv` with its minimums raised to the installed releases,
  the database, `.bazis/ports.json`, the check of Node.js), `bazis.contrib.mcp.rules`
  (`RULES`, `FRONTEND_RULES`, with the same texts) and `bazis.contrib.mcp.prompts` (the
  tasks of a new project, of a package added and of a change, and the steps of a
  frontend). Nothing of them imports Django: `scaffold.product_language(code, python)`
  reads the language of Django of a code with a Python that has Django, such as that of
  the project, and `scaffold.set_language(directory, language)` writes it in
  `project.env` of a skeleton, which `write_files` writes in English.

## Changes

- bazis-mcp no longer depends on bazis: the server never imports the core, it runs the
  project tools with the Python of the project (`--python`, else `.venv`), so
  `uvx bazis-mcp` installs only the server. bazis is in the extra `test` (the sample
  project and the skeleton of the tests). A server run without a Python of the project
  needs the packages of the project in its own Python, as before.

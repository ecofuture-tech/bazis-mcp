# bazis-mcp 2.8.1

## Fixes

- `create_project` writes to `.env` the host and the port of the PostgreSQL server where the
  database was created, not the 5432 of the skeleton when the environment of the server sets
  another one (`BS_DATABASES__DEFAULT__PORT`).
- Stopping a server or a command does not fail on a process group that has already ended:
  `os.killpg` raises `PermissionError` (EPERM) for it on macOS under load, as well as
  `ProcessLookupError`.

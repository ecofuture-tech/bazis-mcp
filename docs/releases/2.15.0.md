# bazis-mcp 2.15.0

## Changes

- **The catalog** describes the latest releases: bazis-front 0.12.0 (it was 0.11.2: the
  fonts served by the frontend itself, with the starters `literata` and `golos-text` that
  `bazis_front design` copies to `frontend/public/fonts/`; the starter layers
  `palette: pine` and `fonts: literata-golos`, the pair of fonts that
  `init --preset portal` names now instead of `source-serif-display`; the mark of the brand
  (`brand` of `theme.yaml`) and the sidebar on its own tokens; the cards of a list
  (`list.card`) and the summary of a card (`card.summary`); a set of values and a negation
  (`{not: ...}`) in a filter; `display.fraction` and `display.per`, `dashboard.today` and
  `dashboard.links`, `controls.date`; the checks S064–S066 and D014–D017; a whole sum
  without zero cents and the input of a date in the format of the language; the format of
  the contract stays 12); the other packages are unchanged.
- **The rules of the frontend** (`bazis://rules/frontend`): after `bazis_front update` they
  run `design` too, before `check`: since bazis-front 0.12 `vite.config.ts` of the template
  imports the fonts that `design` writes (`front.W005` until then).

## Requirements

- A new project with a frontend requires **`bazis-front>=0.12.0`** (it was 0.11.2); it still
  requires `bazis>=2.25.0`, and `add_packages` adds bazis-uploadable as
  `bazis-uploadable>=2.9.0`.

## Upgrading

- The projects already created are not rewritten. An older product takes bazis-front 0.12
  with `pip install -U bazis-front`, `bazis_front update` and `bazis_front design`, as the
  rules say; a scenario or test of its own that expects `,00` in a whole sum or finds a date
  by `input[type=date]` is changed as the release notes of bazis-front 0.12.0 say.

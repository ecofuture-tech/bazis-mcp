# bazis-mcp 2.13.1

## Changes

- **The catalog** describes the latest releases: bazis 2.24.0 (it was 2.23.0: the `type`
  and the `id` of the data of a create or an update document are checked against the
  route, else 409 `ERR_RESOURCE_MISMATCH`; the guide and a pitfall of its manifest say
  so) and bazis-front 0.10.2 (it was 0.10.1: a boolean without a default starts as false,
  `startValue`, and a create form sends it; the hint of S002, P002, D002 and D003 names the
  keys a mapping takes; the warning V021 of `shots`, the table of a list wider than a
  desktop); the other packages are unchanged.
- The rules are unchanged: the agent reads the 409 of the core in its guide and fixes V021
  as every warning of `shots`, by its hint.

## Requirements

- **A new project requires `bazis>=2.24.0`** (it was 2.23.0) and, with a frontend,
  **`bazis-front>=0.10.2`** (it was 0.10.1); the extra `test` requires `bazis>=2.24.0`.

## Upgrading

- The projects already created are not rewritten. An older project takes bazis 2.24 with
  `pip install -U bazis`: its tests and code that send a `type` that the route does not
  answer with (or, on an update, an `id` other than that of the path) get 409: send the
  type of its responses or leave it out. An older product takes bazis-front 0.10.2 with
  `pip install -U bazis-front` and `bazis_front update`, as the rules say.

# bazis-mcp 2.4.3

## Changes

- The catalog describes the latest releases: bazis 2.5.0 (filters reject unknown fields and
  unsupported lookups, `x-bazis` in the OpenAPI schema, the deterministic OpenAPI schema,
  the core declares `AUTH_USER_MODEL` and `AUTHENTICATION_BACKENDS`, the check `bazis.W002`),
  bazis-users 2.5.0 (no default `AUTH_USER_MODEL`; set `BS_AUTH_USER_MODEL`) and
  bazis-authing 2.5.0.
